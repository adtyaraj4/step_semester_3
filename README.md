# STEP Java Assignments — Weeks 1–10

Solutions and source PDFs are organized into weekly folders. Each week has:
- `CW/` — practice problems
- `HW/` — assignment problems

Each folder contains its corresponding PDF and five Java files numbered by problem.

## Contents

- Week 1: Arrays and strings
- Week 2: String operations and frequency counting
- Week 3: Classes, objects, constructors and static members
- Week 4: Array algorithms
- Week 5: Access modifiers and encapsulation
- Week 6: Inheritance and polymorphism
- Week 7: Abstraction and interfaces
- Week 8: Object-oriented system design
- Week 9: Data structures and algorithms
- Week 10: Data structures practice

## Important note about the Java files

The uploaded source ZIP contained the PDFs but no existing Java solutions for Weeks 1–9. Therefore, those folders contain compile-ready scaffolds for the five problem slots; these are **not completed answers**. Week 10 includes the five Java implementations for Smart Home Platform, Customer Registry, Student Marks Grid, Product Price Finder, and Library Platform.

## Compile and run

Run commands from the folder containing the `.java` file. For example, Week 10:

```bash
javac Problem1_SmartHomePlatform.java
java Problem1_SmartHomePlatform
```

For the other files, use the complete filename without `.java` as the class name.
